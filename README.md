# Последний автобус

Одиночный пошаговый рогалик про дорожные бои автобусов. Дизайн — в [GDD.md](GDD.md), план производства — в [PRODUCTION.md](PRODUCTION.md).

## Состояние: M0 (скелет)

Готово:
- `core/` — логика забега без рендера: seeded RNG, генерация карты региона с магазинами на перегонах, билеты пассажиров, выход с оплатой, случайная посадка, еда, расход топлива, действия на остановке, команды и воспроизведение забега.
- `sim/` — боты (`careful`, `greedy`, `random`) и прогон тысяч забегов.
- `tests/` — тесты карты, RNG, билетов, магазинов, фаз и детерминизма.

Заглушки (`core/placeholders.ts`, `core/stubs.ts`): бой, события и босс — броски кубика; контент и числа — константы в коде. Их заменят этапы M1, M1.5 и M3.

## Запуск

Нужен Node.js 22+.

```bash
npm install
npm test
npm run typecheck
npm run sim -- --runs 5000 --bots careful,greedy,random
```

## Правило архитектуры

Состояние меняется только через `applyCommand(state, command)` из `core/commands.ts`. Любой забег воспроизводится функцией `replay(seed, commands)`.
