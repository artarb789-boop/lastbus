# Последний автобус

Одиночный рогалик про дорожные бои автобусов. Бой — в реальном времени с паузой, как в FTL. Дизайн — в [GDD.md](GDD.md), план производства — в [PRODUCTION.md](PRODUCTION.md).

## Состояние: M2 (играбельный прототип)

Игру можно пройти в браузере: `npm run dev`. Графика — заглушки (HTML и SVG), настоящий арт появится позже.

Готово:
- **Контент в данных.** Всё, что может меняться без программиста, лежит в `data/`: баланс, автобусы, оружие, модули, магазины, события, тексты. Каждый файл проверяется JSON Schema из `data/schemas/`, а ссылки между файлами — `core/content-check.ts`.
- **Снаряжение.** Слоты автобуса, установка и снятие, багаж, износ на дорогах, ремонт, механик на посту, пассивные эффекты модулей, бронелисты, закрывающие места у бортов.
- **Магазины** продают ресурсы, оружие и модули, покупают снаряжение за половину цены.
- **События.** Движок условий, требований, проверок и эффектов. 20 событий: в пути, на происшествиях, на обычных и особых остановках.
- **Бак.** Пробивается в бою и в событиях, течёт каждый перегон до ремонта; механик латает его в первую очередь.
- **Бой** (`core/combat/`). Тики с паузой, заряд оружия, цели по системам врага, манёвры и дистанция, уклонение, броня, сцепка, горение, замедление, отрыв, стрелки и механик чинят в бою, медик лечит. 6 врагов с ИИ-профилями и намерениями, босс с фазами, трофеи. Бои — на встречах, в засадах, при перехвате и с боссом.
- **Клиент** (`game/`). Карта региона, салон с рассадкой кликами, снаряжение и багаж, остановки, магазины, события, бой в реальном времени с паузой (пробел) и скоростью ×1/×2/×4, трофеи, итоги. Сохранение — seed и список команд в localStorage: после перезагрузки забег восстанавливается точно.
- **Корпус и системы автобуса:** двигатель, колёса, кабина, бак; повреждения сохраняются, чинятся на остановках.
- **Гонки за остановки.** Соперники выбирают цели на карте; игрок едет обычным темпом, рывком или перехватывает.
- Всё из M0: карта, билеты, выход с оплатой, случайная посадка, еда, топливо, детерминированное воспроизведение.

Ещё не сделано из боя: заклятый соперник, банды из двух автобусов, уникальные трофеи боссов.

## Структура

```
core/     логика без рендера и без чтения файлов
game/     клиент в браузере (Vite, HTML + SVG)
data/     контент и баланс (JSON) + схемы
sim/      боты и прогон тысяч забегов
tools/    загрузка и проверка данных для Node
tests/    тесты
```

## Запуск

Нужен Node.js 22+.

```bash
npm install
npm run dev        # игра в браузере, http://localhost:5173
npm test
npm run typecheck
npm run validate
npm run build      # сборка клиента в dist/
npm run sim -- --runs 5000 --bots careful,greedy,random
npx tsx sim/tune.ts 2000   # сравнить варианты баланса без правки файлов
npx tsx sim/trace.ts 3     # разобрать бои одного забега
```

## Правила для агентов

- Состояние меняется только через `applyCommand(state, command, content)` из `core/commands.ts`. Любой забег воспроизводится функцией `replay(seed, commands, content)`.
- `core/` не читает файлы: контент передаётся явно. Для Node его загружает `tools/load-content.ts`.
- Контент-агент меняет только `data/`, проверка — `npm run validate`. Новый тип эффекта или условия добавляет код-агент в `core/events.ts`, `core/content.ts` и `data/schemas/event.schema.json`.
- Агент баланса меняет только числа в `data/balance.json` и в файлах предметов, проверяет результат через `npm run sim`.
- CI на GitHub гоняет проверку типов, валидацию данных, тесты и короткую симуляцию.
