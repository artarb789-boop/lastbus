# Последний автобус — арт-гайд v0.1

## Направление
Пиксель-арт дизельпанк-постапокалипсиса: практичные формы, читаемые силуэты, пыль, ржавчина, ремонтные заплаты и самодельная броня. Мир суровый, но не хоррор и не гротеск.

## Палитра
Единственный источник цветов — `palette.hex` (30 базовых цветов из лимита 32). Не добавлять произвольные оттенки; для сглаживания использовать соседние цвета палитры.

## Рендер
- Рисовать в целевом размере, без сглаживания и размытия. Масштабирование только nearest-neighbor.
- Контур тёмный, но не чисто чёрный везде; использовать ink, shadow, dark.
- Свет сверху-слева; тёплые блики на металле и стекле.
- Тени компактные и плотные. Детали группировать крупными пятнами, избегать визуального шума.
- Прозрачный фон для игровых спрайтов.

## Размеры
- Автобусы: 160×64 (босс — до 320×96). Вид строго сбоку, нос автобуса направлен вправо.
- Пассажир: 24×32; атлас passengers_atlas.png — сетка 4×2.
- Иконки модулей/оружия: 16×16; атлас icons_atlas.png — 8 ячеек в ряд.
- Фон перегона: 480×135; горизонтальная композиция, пригодная для параллакса.

## Материалы и формы
Автобусы должны выглядеть как переделанный общественный транспорт, а не танки: сохранять узнаваемую линию окон и салона, поверх добавлять бронепластины, багаж, оружейные крепления, фары и ремонтные детали.

## Экспорт и имена
PNG, без интерполяции. Имена файлов — по ID контента. Все спрайты должны использовать только palette.hex.
