# Стиль: пиксель-арт кодом

Игру делает ИИ, поэтому графика рисуется **кодом**, а не генерацией картинок. Спрайт — это матрица символов, где каждый символ — цвет палитры. Это даёт единый стиль, точный контроль и проверяемость: новый спрайт — это несколько строк в репозитории, а не файл, который нельзя прочитать.

Код: [game/art/](../game/art/pixel.ts). Задание для агента, который генерирует картинки, — [ART-BRIEF.md](ART-BRIEF.md).

## Правила

- **Пиксель = символ.** `.` — прозрачно. Матрица рисуется на canvas один раз и кешируется как data URL.
- **Масштаб — только целый.** Спрайты показываются ×3 (сцена боя) или ×3 (пассажиры в салоне) с `image-rendering: pixelated`. Дробный масштаб запрещён: пиксели «поплывут».
- **Палитра.** Общая палитра — `BASE_PALETTE` в `pixel.ts` (контур, металл, стекло, свет, огонь, тень). Своё у спрайта — только цвета корпуса и одежды. Новый цвет в общую палитру добавляется осознанно, не на один спрайт.
- **Свет и настроение.** Снаружи — закат и выгоревшая пустыня. У игрока окна светятся тёплым (`w`, `W`), у врагов в основном тёмные (`b`). Это главный визуальный контраст игры: тёплый автобус в холодном мире.
- **Направление.** Все автобусы смотрят вправо, нос справа, задний фонарь слева.

## Автобусы

Автобусы не рисуются вручную, а собираются генератором `busSprite(look)` из [buses.ts](../game/art/buses.ts). Облик — набор параметров:

| Параметр | Что делает |
|---|---|
| `length` | Длина корпуса в пикселях (40–80) |
| `body`, `trim`, `roof` | Цвета корпуса, полосы и крыши |
| `rust` | Доля пятен ржавчины, 0–0,2 |
| `litWindows` | Все окна светятся (у игрока) |
| `grate` | Решётки на окнах (тюремный автобус) |
| `armor` | Нижние бронелисты с заклёпками |
| `ram`, `spikes` | Таран или шипы на носу |
| `skull` | Череп на борту (заклятый соперник) |
| `tankOnRoof` | Бочка на крыше (сливщики) |
| `roofGun` | `"mg"` или `"rockets"` на крыше |
| `seed` | Зерно для пятен ржавчины и тёмных окон |

**Новый враг** получает облик одной записью в `ENEMY_LOOKS` по его `id` из `data/enemies`. Если записи нет, используется нейтральный ржавый автобус.

Облик автобуса игрока меняется по снаряжению: оружие на крыше, броня на бортах, таран или шипы на носу.

## Пассажиры

7×9 пикселей, сидячая фигурка. Внешность собирается по индексу `look` пассажира: цвет волос, кожи и одежды из небольших наборов в [people.ts](../game/art/people.ts). Раненый — с повязкой на голове. Водитель — в фуражке.

## Анимация

Анимации — CSS, без покадровых спрайтов:
- дюны двух планов и разметка дороги прокручиваются (параллакс);
- автобусы покачиваются;
- выстрел — вспышка у оружия на крыше;
- попадание — белая вспышка спрайта и всплывающее число урона;
- корпус ниже половины — дым, горение или пробитый бак — огонь;
- сцепка гарпуном — пунктирный трос между автобусами;
- пауза останавливает все циклические анимации.

## Сгенерированные картинки

Любой спрайт кода можно заменить картинкой из `assets/img/` — см. [ART-BRIEF.md](ART-BRIEF.md). Игра берёт картинку, только если она утверждена (`approved` в манифесте), иначе рисует кодом. Палитры общие: `game/art/palette.ts`.
